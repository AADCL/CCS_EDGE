# EPGeneral Wheeltec integration

Version: 0.1.0. This ROS package provides UGV_003 native map conversion,
navigation launch files, readiness checks, and the guarded navigation adapter.
It is included by the `wheeltec_r550p` profile during staging.

See the [deployment guide](../../../documents/devices/wheeltec_r550p/DEPLOYMENT_GUIDE.md),
[user manual](../../../documents/USER_MANUAL.md), and
[interface reference](../../../documents/INTERFACE_REFERENCE.md).

Run the package tests from this repository root with
`python -m unittest discover -s devices/wheeltec_r550p/EPGeneral_wheeltec_integration/test`.
